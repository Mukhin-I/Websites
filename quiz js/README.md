## Quiz
Квиз-игра по JavaScript.

## Tech Stack
* JavaScript
* HTML5
* CSS3
* SCSS

## Features
* Подсвечивание правильных/неправильных ответов
* Хранение текущего состояния игры и текущих набранных очков
* Отображение результата в конце игры в зависимости от набранных очков
