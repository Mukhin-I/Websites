## Я Патриот
Я Патриот - Конкурсная работа к 9 мая, сайт посвященный памятным военным событиям и датам.

## Live Demo
https://beamish-duckanoo-67c3b9.netlify.app/

## Tech Stack
* HTML5
* CSS3
* SCSS
* JavaScript
* Figma
* Адаптивная верстка

## Features
* Возможность пройти квиз по памятным датам разных времен
* Знакомство с памятными датами и интересными фактами военных времен
* Адаптивный дизайн
