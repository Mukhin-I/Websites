## Александр Серебряков
Персональный сайт-визитка для композитора, музыканта и преподавателя Александра Серебрякова.

## Tech Stack
* HTML5
* CSS3
* SCSS
* Адаптивная верстка
* Figma

## Features
* Прослушивание последних релизов композитора
* Галерея фотографий с мероприятий
* Просмотр услуг композитора
* Возможность связаться с музыкантом
