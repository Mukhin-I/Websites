## Уют-сервис
Уют-Сервис - платформа для колаборации соседей. Прототип.

## Tech Stack
* HTML5
* CSS3
* SCSS
* Адаптивная верстка
* Figma

## Features
* Возможность добавлять посты в блог
* Возможность реагировать на чужие посты
* Коллаборация между соседями
